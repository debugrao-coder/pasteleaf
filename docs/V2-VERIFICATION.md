## 版本与交付边界

- 起点：`codex/icloud-sync` 的 `4827212fb331160faba9ef1701c03c8c085e7ff7`；实现位于独立 checkout 的 `codex/macos-v2`；实际提交与发布状态以 GitHub 分支、标签和 Release 为准。
- 原有非 Git 的同名目录未修改。初始隔离开发未触碰 Paste；随后按用户明确授权，原 Paste 应用已移入可恢复废纸篓并停用其旧登录 helper，历史数据保留，PasteLeaf 已安装到 `/Applications/PasteLeaf.app`。本轮原生样式更新不读取真实剪贴板正文、不改记录/权限/登录/iCloud 设置，没有连接真实 iCloud 库。
- Mac：原生 SwiftUI/AppKit，Apple Silicon，部署目标 macOS 14.0；本机 ad-hoc 签名，未公开签名或公证。
- Windows：Win32 + Direct2D/DirectWrite，x64 GNU 交叉编译便携预览；MSVC 为后续 Windows 原生构建基线。本机没有可用的 Windows 运行环境。
- Windows 当前使用不透明兼容背景，**半透明合成路径尚未交付**。界面明确提示该边界，没有无效的透明度开关。
- 两端共享语义角色、圆角、卡片几何、状态与分类预设由 `design/tokens.json` 生成；Mac 系统颜色/材质映射也在同一参数源，Windows 保留原生成调色板。Windows 100/150/200% DPI、实际 UI Automation 和全套逐屏视觉验收尚未闭合。

最终候选的 20 张截图及 AX 回读位于 `.artifacts/visual/macos/native-glass/` 根目录，全部来自专用隔离库的 632 条合成记录，没有读取生产剪贴板正文或同步密码。已回读：

- 浅色、深色和不透明降级主面板；浅深色设置、记录与存储、容量说明、iCloud 禁用入口、关于页真实版本号；关闭半透明与减少动画开关可保存并回显。

- 图片和超长中文文件名完整预览、新建收藏夹及禁用创建状态、清空确认后取消、两个冲突版本的标签及滚动表单。正文展开的自动点击没有改变展开状态，**不计为全文展开的 GUI 通过证据**。

## 冲突呈现边界

双端展示版本实际标签、分类、删除语义、来源、时间与附件元信息；图片/文件内容校验使用 BLAKE3。Mac 提供完整正文展开，HTML/原始 RTF 用被动说明及 SHA-256 指纹区分，不执行富文本代码。Windows 正文/HTML 超过 2,048 字符时明确提示截取，并显示完整内容 BLAKE3；这不是全文 diff，RTF 不渲染样式。Windows 实际滚动、焦点与屏幕阅读器体验尚未验证。

## iCloud 与安全切换

双设备往返测试只在普通本地目录模拟；2026-10-12 的真实 iCloud 目录只读预检仅验证版本识别，不含连接、上传或对端接收。`published` 表示写入同步目录，只有加密的对端导入回执可表述该设备已导入；不能称为“云端送达”。

正式试用前需要：

1. 在 Mac 和 Windows 上使用专用合成库。由用户选择 iCloud Drive 专用目录、设置同步密码；勿直接打开旧 v1 同步库。
2. 逐类内容双向往返，核对正文与附件、发布时间和对端导入时间；测试断网重连、睡眠唤醒、错误密码、占位文件、配额/磁盘失败与冲突解决。
3. 双端完成主题、缩放、长文本/文件名、空/加载/失败/禁用状态、全键盘、权限拒绝与目标窗口粘贴；Windows UIA 和 Mac VoiceOver 人工回读。
4. 最后再开启真实记录，确认密码和 Token 也可能被记录、本地库未加密的提示。默认不排除敏感应用，可手动暂停/排除。

本机清空是隐藏本机历史、不传播、不回收云端操作；手动删除会传播，但云端旧操作正文仍可能存在。旧数据迁移先备份且不覆盖旧库，回滚只能使用旧程序和旧数据副本。应用本身不会自动卸载或接管 Paste；本机的卸载/安装来自后续明确用户授权，不代表双端替代验收完成。

这些步骤完成前，不宣布“双端替代完成”或“细节完美”。
