## Rust dependencies

The Windows build uses the versions recorded in `Cargo.lock`. The direct
dependencies are:

| Package | Purpose | Upstream | License expression |
| --- | --- | --- | --- |
| arboard | Clipboard text and images | https://github.com/1Password/arboard | MIT OR Apache-2.0 |
| blake3 | Content hashing | https://github.com/BLAKE3-team/BLAKE3 | CC0-1.0 OR Apache-2.0 OR Apache-2.0 WITH LLVM-exception |
| image | PNG encoding and decoding | https://github.com/image-rs/image | MIT OR Apache-2.0 |
| serde | Data serialization | https://github.com/serde-rs/serde | MIT OR Apache-2.0 |
| serde_json | JSON storage | https://github.com/serde-rs/json | MIT OR Apache-2.0 |
| windows-sys | Windows API bindings | https://github.com/microsoft/windows-rs | MIT OR Apache-2.0 |

`scripts/package.py` resolves the locked `x86_64-pc-windows-msvc` dependency
graph offline. It collects license, copying, copyright and notice files from
each selected crate in the local Cargo registry, including build dependencies
and procedural macros. This conservative inventory contains 55 third-party
packages for the current lockfile; it does not claim every package is linked
into the executable. Other targets may use additional packages.

Every portable ZIP contains `third-party/DEPENDENCIES.json`, listing the
resolved package versions, source repositories, declared license expressions,
and included license files. The original texts are in the corresponding
`third-party/<package>-<version>/` directories. In particular,
`unicode-ident` also requires the Unicode license; its full bundled license
file is preserved rather than selecting only MIT or Apache-2.0.

The `clipboard-win` 5.4.1 crate declares `BSL-1.0` but omits the license text
from its published crate archive. For this exact version, the packager uses
the official [Boost Software License 1.0](https://www.boost.org/LICENSE_1_0.txt)
text stored in `license_assets/BSL-1.0.txt`. Its source and SHA-256 are recorded
in `license_assets/SOURCES.json` and in the ZIP inventory. Packaging verifies
that hash and fails on other missing license files; it never fetches replacement
license text from the network.

## Rust standard library and Windows

The executable statically links the Rust standard library. Its copyright
document and license texts from the selected Rust toolchain are included under
`third-party/rust/`. These are upstream toolchain notices; the package inventory
also records the compiler version. The Rust project is primarily licensed
under MIT OR Apache-2.0, with additional notices documented in
`COPYRIGHT-library.html`.

The build also uses the Microsoft MSVC C runtime and Windows SDK under their
respective Microsoft terms. The C runtime is linked statically; Windows system
DLLs, SDK headers, and development tools are not distributed in the ZIP.

## Icon

`assets/pasteleaf-icon.png` and `assets/pasteleaf.ico` are original geometric
artwork generated by `scripts/generate-icon.py`. The script draws the clipboard
and leaf with gradients, rounded rectangles, and Bézier curves; it does not
import an external logo, image, or font. These assets are covered by the project
MIT license.

Regenerating the icon requires [Pillow](https://github.com/python-pillow/Pillow),
which uses its own [license](https://github.com/python-pillow/Pillow/blob/main/LICENSE).
Pillow is a development tool and is not bundled with PasteLeaf.

interactions do not imply affiliation with another product.
